# java-testing-exercises

A collection of Java practice exercises focused on document automation and browser-driven testing. This is a personal learning project and is not intended for production use.

## Exercises

| Folder | Contents |
|---|---|
| `Ejercicio 1` | Exercise description document (`Ejercicio 1.docx`) |
| `Ejercicio 2 y 3` | Maven project with ChromeDriver, JSON request fixture, test sources and captured screenshots |
